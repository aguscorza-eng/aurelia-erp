# Reglas de negocio

## Productos

La empresa fabrica:

- Velas
- Difusores
- Souvenirs
- Hornitos
- Aromatizantes
- Gift Boxes

## Ventas

Canales:

- Instagram
- WhatsApp

## Producción

Todos los productos se fabrican internamente.

Cada producto tendrá una receta de fabricación.

## Stock

No se modifica directamente.

Todo movimiento genera un registro.

Tipos de movimiento:

- Compra
- Producción
- Venta
- Ajuste
- Rotura

## Objetivo

El sistema deberá calcular automáticamente:

- Costos
- Ganancias
- Márgenes
- Stock disponible
- Productos más vendidos
